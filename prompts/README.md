# Prompts

Standalone prompts not yet promoted to skills.

A prompt moves to `skills/` once it has a clear "use when" trigger and has been reused at least twice.

Each prompt file starts with frontmatter:

```yaml
---
title: Short descriptive title
target_model: claude-opus-4 | any
purpose: One sentence on what it is for.
status: draft | tested | promoted
---
```
